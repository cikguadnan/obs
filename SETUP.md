# Setup Checklist

## A. Google Sheet

Create a blank Google Sheet named, for example:

**OBS Afterglow Responses**

The Apps Script will create the `Responses` tab and headers automatically.

## B. Apps Script

Copy `Code.gs` into Extensions → Apps Script.

Deploy as a Web App and copy the deployment URL.

After changing Apps Script code later, deploy a **new version** through:

Deploy → Manage deployments → Edit → New version → Deploy

## C. Website configuration

Edit `config.js` and paste the deployment URL.

## D. Test

1. Open the student page.
2. Submit one test response.
3. Confirm that a new row appears in Google Sheets.
4. Open the dashboard.
5. Press Refresh.
6. Test Approve, Hide and Favourite.
7. Open Show Class mode.

## E. Before the lesson

- Use a QR code for the student page.
- Keep the dashboard URL private.
- Review responses before projection.
- Test the projector and full-screen mode.
- Prepare a backup copy of the Google Sheet.
